# StudyStep content

Published question banks for [StudyStep](https://apps.apple.com/app/studystep).
The app reads `v1/manifest.json`, compares its version with what it has, and
downloads the files whose hashes changed. The copy inside the app is a floor:
if this host is unreachable, or anything here fails to decode, the app carries
on with the questions it shipped with.

Generated by `ContentPipeline/publish.py` in the app repository. Nothing here
is edited by hand — a correction is made in the question source, run through
the build gates, and republished.
